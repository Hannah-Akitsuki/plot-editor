这是干什么的

把一部剧 / 一部小说的剧情、角色、世界观摊在一张无限画布上整理：左侧切换模块，中间是画布，右侧是属性与大纲，底右角是工具栏。手机 / 平板上同样可用（手势见「触屏」分页）。

界面布局

  • 顶栏：新建 / 保存 / 导入 / 搜索 / ＋便签 / ＋图片；右侧是「? 帮助」和「设置」。低频功能都收在「更多 ▾」里（见下）。
  • 文件标签栏：当前打开的文件（剧情、角色库……），可多开，Ctrl+Tab 切换。标签右键可重命名、归档进文件夹、关闭；文件夹条可以整组打包导出。
  • 左侧模块栏：剧情 / 角色 / 关系 / 世界观 / 时间线 / 地图 / 设定，点击即进入对应模块。
  • 右侧面板：上部是画笔色轮与吸管（画布类模块），中间是选中对象的属性，下方是大纲图层面板（合集=可折叠图层组、便签=叶子；可拖动排序、拖进 / 拖出集合、触屏长按拖动；顶部搜索框可筛便签标题 / 正文 / 合集名 / 轴名 / 轴点名，双击或 F2 改名）。Tab 或面板右缘的 ▶ / ◀ 小把手可显示 / 隐藏面板。
  • 右下角工具栏（剧情画布内）：选择 / 涂鸦笔 / 橡皮 / 连线模式 / 轴模式 / 线色 / 只看剧情。

「更多 ▾」菜单

  • 另存为：导出当前项目为 .plot 文件；打包：整个项目（含图片、涂鸦、文件夹）合成一个 .ocpkg 包分享。
  • 协同：局域网多人同编；统计：字数与完成度；检查：剧情一致性体检；数据自检：悬空引用 / 重叠便签 / 重复 id 体检（也可 Ctrl+Shift+J）；设定集：导出可搜索的 HTML；总览：全项目一览直达。
  • 工具子菜单：伏笔清单 / 查找替换 / 回收站 / 备份快照。
  • 按模块变化的按钮：导图（剧情模块，选中便签后出现）、设定MD（角色 / 世界观 / 时间线 / 设定库）、＋添加角色（关系图）。

新建文件

顶栏「新建」可选：总览板 / 剧情画布 / 角色 / 关系图 / 世界观 / 时间线 / 地图 / 设定库——同一部作品可开多个文件标签（剧情可分卷分集）。

改动会自动保存，不必担心丢内容；「保存」按钮用于立即写盘。撤销 Ctrl+Z，重做 Ctrl+Y（约 80 步）。

新建便签的三种方式

  • 顶栏「＋便签」按钮；画布空白处双击——建在双击位置并立即命名；快捷键 N——建在画布中央。
  • 在某个集合框范围内新建的便签会自动加入该集合，不用再去大纲里拖。

便签编辑

  • 改标题 / 正文：双击便签进入编辑，点其它位置完成；或选中后按 F2 改名。
  • 颜色：选中便签 → 右侧面板色轮改标题底色 / 正文底色 / 文字颜色；色轮旁吸管可从任意同类对象取色。
  • 缩放：拖便签右下角把手；图片便签等比缩放。
  • 多选：空白处拖框选，或 Shift+点击追加，Ctrl+A 全选。
  • 对齐 / 等距：选中 ≥3 张便签后右键 →「对齐与分布」，可选左 / 水平居中 / 右、上 / 垂直居中 / 下，以及水平 / 垂直等距；轴上的便签不参与（位置由轴排版推导），操作可 Ctrl+Z 撤销。
  • 删除：Delete。删除的东西进回收站（最多 40 条），「更多 → 工具 → 回收站」可恢复。

集合（编组）

  • 创建：多选后右侧面板「成组」（或 G / Ctrl+G）；Shift+G 解散。
  • 移动：集合可整体拖动（拖标题条），也可把便签拖进 / 拖出集合框（松手在集合范围内即移入）。
  • 脱离集合：桌面按住 Alt+点击便签，一键脱离所有集合；也可以右键便签 →「移出集合」，或在右栏大纲里把便签拖出集合。
  • 嵌套：一个集合的全部成员落在另一个集合范围内时，自动成为其子合集（最多 5 层）；把子合集拖出父框即自动解除嵌套。
  • 整组关联：选中集合后右侧面板可把整组关联到某个角色 / 地点等内容。

大纲图层面板

  • 层级：合集是可折叠的图层组，合集套合集最多 5 层；便签是组里的叶子。没有加入任何合集的便签集中在虚拟「未分组」区（只影响显示，不写进文件）。轴在下方单独列出其挂载便签与点名，只读。
  • 折叠：点合集 / 未分组 / 轴行首的箭头收起或展开。
  • 拖动排序：桌面鼠标直接拖；触屏按住约 0.5 秒再拖（短按仍是定位，滑动仍是滚动）。蓝色横线是插入位置。拖到合集标题 = 加入该组；拖到「未分组」或组外空白 = 移出合集；同级拖动只调整顺序。只改大纲顺序与合集归属，不改画布坐标。
  • 搜索：顶部搜索框实时过滤便签标题 / 正文、合集名、轴名、轴点名，命中高亮，包含命中的组自动展开；回车飞到第一个命中，Esc 清空。快捷键 Ctrl+Shift+F（Ctrl+F 是原有全局搜索）。
  • 改名 / 定位：双击名称或 F2 改名；单击行仍会飞到画布对应对象（轴行飞到整条轴，轴点行飞到该点）。

人物成长线

  • 在哪：角色模块选中角色 → 右侧面板切到「成长线」页签（页签上有节点计数）。
  • 加节点：在「事件」下拉里选画布上的便签或轴点（只引用不复制正文），可填该角色视角的一句话与关系标记（如：主导 / 目击者，均可留空），点「加入成长线」。重复添加同一事件会被拦下。
  • 排序：按章节顺序自动排列——章节取轴 / 合集在文件里的顺序（轴在前、合集次之、都没进线的放「其他 / 未入线」）；同一章内轴上事件按轴点 / 挂载位置排序，其余按加入时间。
  • 联动加节点：添加时把「同时记到」选成另一个角色，对方成长线会生成指向同一事件的节点（视角各自填）；不选则完全不联动，只写进当前角色。
  • 角色关联：在「角色关联」区选角色和类型（羁绊 / 对手 / 师承 / 血亲 / 背叛）点「建立」，两端互相可见；点任一端的 × 解除，另一端自动同时清除。删角色、删被引用的便签或轴点时，相关条目也会自动清理，不留断头。
  • 跳转 / 移除：节点行的 → 飞到画布对应便签或轴点；× 只把这一条从成长线移除，不影响画布内容。视角一句话直接在行内改（失焦即保存），Ctrl+Z 可撤销。

跨模块关联（剧情 ↔ 角色 / 地点 / 名词 / 事件 / 文件）

  • 建立：右键便签 → 「＋ 关联到…」；一张便签可有多个关联，点已关联项 = 移除。
  • 🔗 角标：便签右上角的小标签。悬停显示全部关联名；点击展开 / 收起关联列表；点列表条目直接跳转过去。
  • 关联卡片：右键便签 →「转为关联卡片」，便签缩成小药丸挂在画布上（不挡剧情），点击展开 / 收起；右键它选「恢复为剧情便签」复原。
  • 只看剧情：工具栏开关。一键隐藏所有关联卡片和关联连线；状态会记住。
  • 关联聚焦：选中便签按 F，相关的保持清晰、无关的变暗，再按一次恢复。

文本块

编辑正文时选中一段文字按 T，这段文字会被细虚线框住并记作文本块，可单独连线（如「这句话伏笔指向某事件」）、右键设关联、或「扩充为独立便签」。编辑中没有选中文字时按 T 只是正常打字。

连线模式直接拖：切到「连线模式」后，从带虚线框的句子拖到另一个便签 / 文字块即可（也可依次点击两端）。点工具条会自动退出正文编辑，不会再把拖动当成选字。

同色标签：文字块一旦有连线和关联，句子会染上关联对象的颜色，句尾出现同色小标签（名字 / 线名）。点文字块 → 色板可直接改色；按 I 再点任意带颜色的对象（角色标签、便签、集合、线条、文字块）即可吸色。吸到的颜色同时用于文字底色和句尾标签；「恢复跟随关联色」可回到自动配色。

伏笔标记

右键便签 →「伏笔标记」：标为已埋 / 已回收 / 弃坑，可附备注；便签角落出现圆点角标。「工具 → 伏笔清单」汇总全部伏笔；「检查」会提醒还没回收的伏笔。

图片便签

顶栏「＋图片」插入本地图片，也可以直接 Ctrl+V 粘贴截图；可调边框底色、等比缩放，也能参与关联。

轴模式是干什么的

把一段剧情按顺序排在一条「轴」上（比如主线轴、某角色线），用来检查节奏和时间顺序。

完整流程

  • 建轴：A 进轴模式 → 点第一个便签作「头」→ 再点一个作「尾」，自动生成轴。轴的名字 = 头便签的标题。
  • 轴的颜色：轴模式 / 连线模式下工具栏的「线色」决定新轴颜色；选中轴后右侧面板也能改。
  • 整体操作（选择模式）：轴是一个整体——点轴梁或成员即选中整条轴、拖动轴梁整体移动、Delete 删除轴及轴内全部便签（可在回收站恢复）。右侧面板可选「解散轴」：只删轴和点，便签原地保留。
  • 挂载 / 卸载：把便签拖到轴上 = 挂载，拖离 = 卸载；直接拖动轴上的便签即可调整位置（选择模式、轴模式都行，不必切换）。同轴便签叠在一起时会自动往下挤开；文字行数变多时下方的便签也会自动往下推移。
  • 打点：双击轴上任意位置添加一个「点」并命名（选择模式下双击轴梁也可以）。
  • 点的关联与跳转：选中点后在右侧面板可关联到其他便签，之后点击即可跳转过去。
轴模式下 Esc 退出。轴线会和普通连线一样随便签移动实时跟随。

七大模块

  • 剧情：无限画布，本指南大部分内容都在讲它。
  • 角色：卡片列表。选中角色后右侧面板可上传 / 粘贴头像、改主题色与标签、编辑设定字段、拖六维属性滑杆；「状态轴」记录角色在不同卷 / 章的状态变化（如：黑化 · 第三卷）；「导出人设卡」生成 900×1200 的 PNG 图片。
  • 关系：角色关系图。顶栏「＋添加角色」加入已有角色，拖动摆位；从一个角色拖到另一个即连关系线，点连线可命名关系（如师徒 / 敌对）；可建分组（阵营 / 势力）把角色圈在一起，分组可命名、解散。
  • 世界观：分栏文本设定（可建多个条目）。
  • 时间线：按时间排列的事件轴，事件可改时间 / 标题 / 描述 / 颜色；剧情便签右键「链接到时间轴」可把便签插到某事件之后。
  • 地图：地点合集，点地点卡编辑名称与描述，可与剧情关联。
  • 设定：名词设定库（名词 / 术语 / 设定卡）。

生成与总览

  • 导图（剧情模块，选中便签后顶栏出现）：把选中的剧情便签生成思维导图。默认「横向」布局（根在左、逐级向右展开），可切「左右分列」（根居中、一级分支分向两侧）；一级分支各有一套色系，层级越深越淡。顶部字号控件统一缩放所有层级，节点尺寸 / 行距 / 层间距随之自适应；点节点右侧圆点折叠或展开分支，滚轮缩放、拖动平移、双击或「适配」一键看全图；长文本自动换行。可导出 SVG / OPML（OPML 可直接导入 XMind、幕布）。
  • 总览：全项目内容一览，点击任意条目直达。
  • 设定集：把世界观 / 角色 / 关系 / 名词 / 地点 / 时间线 / 剧情排版成可搜索的 HTML 文件。
  • 设定MD：角色 / 世界观 / 时间线 / 设定库模块下，把当前模块导出为 Markdown。

画布基本操作（鼠标）

  • 平移：按住 空格 拖动，或按住鼠标中键拖动。
  • 滚动：滚轮上下滚动画布，Shift+滚轮左右滚动。
  • 缩放：Ctrl+滚轮（触控板捏合同效）；Ctrl+= 放大 / Ctrl+- 缩小 / Ctrl+0 复位 100%。
  • 微调：选中后方向键移动 1px，Shift+方向键移动 10px；Home 或画布右下角「回到内容」按钮一键取景全部便签（画布拖丢了按它就回来）。
  • 连线：连线模式下从便签拖到便签；左键点线可选中（右侧面板命名 / 改色），双击线快速改名。
  • 吸色：吸管是临时动作——点同类对象取色；Esc / 再点吸管 / 点空白 都能取消。

F1 或 ?（Shift+/）打开本说明全局
输入法打字过程中快捷键不会误触发；在输入框里按 Esc 是退出编辑。

手机 / 平板（触屏）

安卓 APK 和手机浏览器里界面会自动切换为触屏布局：右侧面板收起为抽屉，点屏幕右缘的 ▶ / ◀ 把手展开 / 收起，抽屉整体可上下滚动。

画布手势（剧情模块）

  • 单指拖空白：平移画布；单指拖便签：移动便签（拖到轴上即挂载、拖进集合框即移入）。
  • 双指捏合：缩放画布，双指拖动同时平移。
  • 双击空白：新建便签；双击便签：编辑文字；点按：选中。
  • 长按：画布上弹出右键菜单（便签 / 集合标题 / 连线通用）；大纲行上是拖动排序（约 0.5 秒）；长按空白 = 画布菜单：在此新建便签、粘贴、回到内容；也可以直接点画布右下角工具条上的「回到内容」按钮，画布拖丢了用它一键找回。
  • 框选是鼠标专属，触屏请用集合来整组移动。

其它模块手势

  • 角色 / 世界观 / 时间线 / 地图 / 设定：直接上下滑动浏览，双指捏合可放大页面看小字。
  • 关系图：整个图可在画布内滚动浏览（图最小 920×640），单指拖角色调整位置、拖出关系线；分组圈随成员自动包裹。
  • 集合脱离在触屏上用：长按便签 → 移出集合。

文件

  • APK 里「导入」会调出系统文件选择器；导出的文件保存到下载目录。
  • 用「打开方式」选择本应用，可直接打开 .ocpkg / .plot 文件。

保存与自动保存

  • 桌面版（exe）：所有改动自动保存到本机，顶部「保存」或 Ctrl+S 立即写盘；「另存为」导出单个剧情文件（.plot）。
  • 导入：「导入」按钮或把 .plot / .json / .ocpkg 文件直接拖进窗口；旧版文件也能兼容打开。
  • 打包：「更多 → 打包」把整个项目（含文件夹结构、图片、涂鸦）合成一个 .ocpkg 包分享给别人，对方导入后原样还原；也可按文件夹整包导出。
  • 备份快照：每 12 小时自动存一份（最多 5 份），「更多 → 工具 → 备份快照」可手动查看 / 恢复。
  • 保存备份（仅桌面版）：每次 Ctrl+S 覆盖前，会把旧文件滚存到同目录「备份」文件夹（命名 原名.20261106-153000.扩展名），只保留最近 5 份；备份失败不影响保存，只在本次运行提示一次。
  • 回收站：删除的内容先进回收站（最多 40 条），可恢复；「关闭文件」也是可恢复删除。

局域网协同

「更多 → 协同」开启后，同一 WiFi 下其他人用浏览器打开提示的地址，即可一起编辑，约 4 秒自动同步一次。

配套工具（都在「更多」里）

  • 搜索（顶栏 / Ctrl+F）：跨全部模块搜剧情、角色、设定、事件。
  • 统计：字数、便签数、完成度（可设每日字数目标）。
  • 检查：剧情一致性体检——时间线倒流、已死角色出场、从未被提及的设定、失效关联、未回收伏笔。
  • 数据自检（Ctrl+Shift+J）：数据健康体检——连线端点悬空、便签关联 / 文字块关联 / 轴点关联失效、集合成员或父合集悬空、零长度线、便签重叠、孤儿合集、重复 id；点条目定位，「一键修复」只删明确的坏引用（修前自动存快照，可撤销）。
  • 工具：伏笔清单 / 跨文件查找替换 / 回收站 / 备份快照。
  • 设置：10 款主题换色、每日字数目标、快捷键自定义（点条目后按新组合键）。
多入口说明：同一部作品可开多个文件标签（剧情可分卷分集），左侧模块栏是七类模块的入口，两者配合使用。
